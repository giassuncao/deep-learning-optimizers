# Deep Learning Optimizers
Giovanna Assunção Pereira Soares

A repository to make available and organize the codes developed during the execution of a [technical note on Medium about Optimization in Deep Learning](https://medium.com/@giovanna.assuncao.705/otimização-no-deep-learning-5f451be97004). These codes enable practical visualization of the theoretical concepts covered in the work, this is part of the coursework for the Machine Learning course by professor [Ivanovitch Medeiros](https://github.com/ivanovitchm).

The code in the .ipynb files can be found under 'files' in this repository or accessed directly through these Google Colab links:

[1. Visualizando Gradientes Adaptados](https://drive.google.com/file/d/1_HA7nldYSW963NO9UAITE3GVjzNbuSLn/view?usp=sharing): Code to help visualize the changes in gradients, corrected gradients, and adapted gradients throughout model training, using EWMA and the Adam optimizer.

[2. SGD Momentum e Nesterov](https://colab.research.google.com/drive/1BWbOyp0pPpTqaMsjRJgJPEGjQMeJmWDf?usp=sharing): Code to help compare the behavior of SGD optimizer in three ways: normal, with momentum, and with Nesterov momentum. Analyzing gradients, path and loss functions.

[3. Learning Rate Schedulers](https://colab.research.google.com/drive/1fhcGBYiXNEm_quEwdkFYyavdCRcrgTNG?usp=sharing): Code to help understand the differences in a model training using learning rate schedulers, specifically StepLR and CyclicLR.

[4. Putting It All Together](https://colab.research.google.com/drive/1jjBcTrc6S8KwzgO7LravGYWpzQrgJ1gL?usp=sharing): Code that incorporates all the theoretical concepts presented throughout the work, using an image dataset to explore and understand the behavior of the studied optimizers.
